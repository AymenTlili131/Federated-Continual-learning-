\begin{abstract}
Understanding the geometry and topology of neural network weight spaces is fundamental to advancing deep learning theory. We introduce a novel framework for analyzing neural networks through \emph{hyper-representations}---learned embeddings of network weights that capture their functional and topological properties. Our approach leverages multiparameter persistent homology to extract robust topological features from weight space trajectories during training. We systematically evaluate 18 diverse loss functions across three data overlap scenarios, training over 51 models to construct a comprehensive weight space atlas. Using transformer-based autoencoders, we learn compact hyper-representations that preserve both local geometric structure and global topological invariants. Our multiparameter persistence analysis reveals that different loss functions induce distinct topological signatures in weight space, with regularized combinations exhibiting superior stability. Statistical analysis demonstrates strong correlations between topological features and generalization performance, with effective rank and persistence entropy emerging as key predictors. This work establishes hyper-representations as a principled framework for neural network analysis, opening new avenues for architecture design, training optimization, and transfer learning.
\end{abstract}
